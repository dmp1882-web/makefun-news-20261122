A program that writes one image summing up the world news of Sunday 22 November 2026: the COP31 climate talks collapsing with no deal, the Democrats winning their largest US House majority since 1992, two tankers hit by mines near the Strait of Hormuz, a Russian warship hit at Benghazi port, drone strikes on Khartoum damaging a UN building, and a factory fire in Indonesia killing 24. The image is stored base64-encoded as entry.png.b64 and main.py decodes it when it runs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
